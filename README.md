# Retail Data Governance

A data governance project focused on profiling, cleaning, validating, securing, and analyzing a retail dataset, including data quality, privacy, encryption, access control, and regulatory compliance.

##  Project Overview

This project was developed as part of the **DSAI202 – Data Governance** course.

The project focuses on transforming an unclean retail dataset into a reliable, validated, and secure dataset while applying data governance principles.

### The project covers:

- Data Profiling
- Data Cleaning
- Data Validation
- Data Quality Assessment
- Data Visualization & Dashboarding
- Sensitive Data Hashing
- RSA Encryption & Decryption
- Attribute-Based Access Control (ABAC)
- Privacy & Regulatory Compliance
- RSA Attack Demonstration
- Machine Learning Preprocessing
